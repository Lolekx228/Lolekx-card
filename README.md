# Lolekx-card v0.3.3

Статическая bio-card с локальной админкой.

## Как запустить локально

Не открывайте `admin.html` и `index.html` двойным кликом через `file://`: поведение `localStorage` между файлами в таком режиме зависит от браузера.

```bash
python3 -m http.server 8000
```

После этого откройте:

- `http://localhost:8000/` — карточка;
- `http://localhost:8000/admin.html` — настройки.

## Как публиковать настройки

`Сохранить локально` меняет только `localStorage` текущего браузера — это удобно для предпросмотра, но другие посетители сайта эти изменения не увидят.

Для статического хостинга (например GitHub Pages):

1. Настройте профиль в `admin.html`.
2. Нажмите **Экспорт profile.json**.
3. Замените файл `profile.json` в проекте экспортированным файлом.
4. Закоммитьте/загрузите изменения на хостинг.

`index.html` сначала читает публичный `profile.json`, а затем применяет локальные настройки браузера поверх него.

## Важное про загружаемые файлы

Локальные изображения, курсоры, обложки и музыка теперь сохраняются как Blob в `IndexedDB`. В интерфейсе нет искусственного ограничения по размеру файла; фактический предел задаётся свободным местом и квотой конкретного браузера/устройства. При экспорте `profile.json` локальные файлы автоматически преобразуются в Data URL, чтобы экспорт оставался переносимым.
