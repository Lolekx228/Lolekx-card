# Lolekx-card v0.2.0

Статическая bio-card с локальной админкой.

## Как запустить локально

Не открывайте `admin.html` и `index.html` двойным кликом через `file://`: поведение `localStorage` между файлами в таком режиме зависит от браузера.

```bash
python3 -m http.server 8000
```

После этого откройте:

- `http://localhost:8000/` — карточка;
- `http://localhost:8000/admin.html` — настройки.

## Как публиковать настройки

`Сохранить локально` меняет только `localStorage` текущего браузера — это удобно для предпросмотра, но другие посетители сайта эти изменения не увидят.

Для статического хостинга (например GitHub Pages):

1. Настройте профиль в `admin.html`.
2. Нажмите **Экспорт profile.json**.
3. Замените файл `profile.json` в проекте экспортированным файлом.
4. Закоммитьте/загрузите изменения на хостинг.

`index.html` сначала читает публичный `profile.json`, а затем применяет локальные настройки браузера поверх него.

## Важное про загружаемые файлы

Локальные изображения и MP3 кодируются в Data URL и попадают в `localStorage`, поэтому для них введены ограничения размера. Для музыки и крупных изображений лучше использовать обычные `https://` URL — поля URL есть в редакторе аудио.

## Что исправлено в v0.2.0

- исправлены недействительные после перезагрузки `blob:`-ссылки для загруженных MP3;
- добавлены URL-поля для аудио и обложки;
- добавлена обработка переполнения `localStorage` и лимиты на локальные файлы;
- `Регулятор громкости`, `Цвет иконок`, `Монохромные иконки`, `Поменять блоки местами`, пользовательский курсор теперь реально влияют на профиль;
- переключатели Discord, для которых нет источника данных/API, явно отключены вместо ложной видимости работы;
- настройка анимированного заголовка теперь реально включает/выключает анимацию;
- плеер скрывается, если отключён или нет валидных треков;
- исправлено поведение shuffle: случайный трек выбирается при каждом открытии;
- добавлены проверки URL, `rel="noopener noreferrer"`, обработка ошибок `audio.play()` и безопасный вывод названий треков;
- добавлен публичный `profile.json` и экспорт из админки.
